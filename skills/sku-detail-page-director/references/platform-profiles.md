# 平台适配速查

阶段二或三仅读取目标平台对应小节。下列内容是信息与视觉优先级，不是可以编造的商品卖点。

## 国内货架电商：淘宝、天猫、京东、拼多多

- 默认中文；信息密度中高，卖点、规格、细节和购买理由要清晰。
- 优先功能转化或功能+场景混合；移动端连续阅读优先于纯氛围。
- 将尺寸、材质、参数、适配等未确认内容留给用户资料和后期校对。

## 国内内容电商：抖音商城、小红书

- 默认中文；首屏钩子、真实场景、短句文案和低阅读负担优先。
- 优先场景种草或场景+质感混合；让用户在一秒内看懂“是什么、为何继续看”。
- 不用夸张功效、伪前后对比或不真实的生活方式掩盖事实不足。

## 海外搜索电商：Amazon、eBay、AliExpress

- 默认英文；功能利益、规格、兼容性、FAQ、可信度和合规表达优先。
- Listing 图片与 A+ 模块根据用途选择比例，不能强塞进 9:16。
- 所有性能、兼容型号、认证、评价和比较结论都必须有用户资料支持。

## 海外品牌/独立站：Shopify、独立站

- 默认英文，可按要求中英双语；品牌世界观、场景、生活方式与转化路径并重。
- 可使用高端质感、场景种草或品牌生活方式方向，但先明确产品实际卖点与价格带。
- 社交证明、售后、品牌故事不由图片推断；只在用户确认后写入。

## 海外内容电商：TikTok Shop、Etsy

- 默认英文；视觉冲击、短句利益点、礼品/UGC 氛围和快速理解优先。
- 场景种草、礼品氛围或视觉冲击可作为方向，仍要保留产品身份与真实使用边界。
- 避免把概念图、AI 文本或未经证实的声明当作上架素材。

## 默认屏数

| 目标 | 建议 | 典型结构 |
| --- | --- | --- |
| 快速上新 | 5 屏 | 首屏 → 场景/痛点 → 核心卖点 → 细节 → 购买理由 |
| 普通 SKU | 6 屏 | 首屏 → 场景 → 卖点 → 细节 → 使用/资料 → 收尾 |
| 信息完整 | 8 屏 | 首屏 → 痛点 → 功能 → 细节 → 工艺/结构 → 使用 → 规格 → FAQ/收尾 |
| 高客单/复杂 | 8–10 屏 | 增加生活方式、疑虑处理和使用指南；不凭空补充品牌故事或参数 |
