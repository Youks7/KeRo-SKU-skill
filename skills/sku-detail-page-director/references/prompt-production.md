# 逐屏 Prompt 与生产规则

阶段三或首屏 A/B 才读取。本文件不替代 `core-guardrails.md` 的事实与保真边界。

## Prompt 的组成顺序

按屏幕目的选择必要项，不要把所有形容词塞入一个 Prompt：

```text
{画面用途与商业摄影类型}
{空间/背景/构图与产品预留区}
{镜头距离、角度、景深与光源方向}
{本 SKU 的两个专属细节或受控场景线索}
{色彩、材质感和情绪}
{留白与文字安全区}
{模式特定约束}
```

画面模型通常更适合英文 Prompt；保留中文的画面意图、后期文案和质检说明。用户已指定模型或语言时服从其要求。

## 模式 A：背景与真实产品合成

**Prompt 可写：** 背景、场景、光影、表面材质、道具、空间、抽象隐喻、摄影风格、色彩、景深、阴影方向、产品预留区和文字安全区。

**Prompt 禁写：** 产品本体、产品包装、品牌 Logo、包装文字、标签、最终标题、卖点、参数、CTA、虚假认证、具体未确认规格或替代产品。

合成说明必须给出：

1. 真实产品放入的位置、视角和比例。
2. 主光与接触阴影方向。
3. 环境色/反射处理。
4. 边缘、白边和透视一致性检查。
5. 文字与 Logo 的独立图层位置。

## 模式 B：参考图驱动的商品图

Prompt 开头包含：`Use the uploaded product image as the only product reference.`

随后明确保持：产品类别、主颜色、SKU 颜色、主要结构、Logo、包装文字及关键外观；只允许优化背景、场景、光影、阴影和商业摄影质感。不要要求模型生成人物文字、包装文字、认证或不存在的配件。

生成后逐项检查原图与结果：颜色、结构、SKU 版本、Logo/文字、包装、配件和重绘痕迹。任何关键项错误，标为不可用于成品，重新生成或切换模式 A。

## 模式 C：概念探索

Prompt 块开头标明：`Concept exploration only — not a real SKU production asset.`

可以描述假设的产品概念，但不得借此输出未经证实的规格、材质、功效、认证或商业承诺。进入真实售卖制作时，必须改用模式 A 或 B。

## Negative Prompt

按风险选择，而非无差别复制长串。常用基础项：

```text
text, letters, logo, watermark, typography, numbers, label, fake product,
wrong product variant, distorted geometry, duplicate objects, fake packaging,
fake certification, random icons, messy layout, low resolution, blur,
overexposure, harsh shadow, oversaturation, generic e-commerce template
```

可按屏幕附加错误视角、手部畸形、失真反射、杂乱背景等具体风险。模式 A 可加 `product, packaging`，以防背景图产生替代商品。

## 镜头矩阵与视觉节奏

为每屏记录以下值，并保证相邻屏至少有两项变化：

| 项目 | 选择范围 |
| --- | --- |
| 距离 | 远景 / 中景 / 近景 / 微距 |
| 角度 | 正视 / 俯视 / 侧面 / 45° / 低角度 / 逆光 |
| 产品状态 | 静置 / 使用中 / 开箱 / 局部特写 / 手部互动 / 场景摆放 |
| 背景 | 纯棚拍 / 生活空间 / 户外 / 桌面 / 材质背景 / 功能场景 |
| 光线 | 自然窗光 / 柔光棚拍 / 硬光阴影 / 逆光轮廓 / 清晨光 / 夜间氛围 |
| 道具 | 无 / 功能道具 / 场景道具 / 尺寸参照 / 使用痕迹 |

禁止连续使用“居中悬浮 + 渐变背景 + 柔光 + 三图标”的同一组合。视觉统一来自色彩、字体气质、光线逻辑和留白秩序；变化来自构图、景别、情境和销售任务。

## 最终质检

每屏交付前回答：

1. 是否把推断或缺失信息当成了商品事实？
2. 模式是否与产品风险匹配，Prompt 是否遵守该模式？
3. 是否出现/要求生成最终文字、Logo、包装、认证或 CTA？
4. 两个专属细节是否真正来自本 SKU，而非万能形容词？
5. 若替换成同类产品，画面是否仍完全成立？若成立，重写。
6. 与上一屏是否有不同的销售任务和至少两个镜头维度差异？
7. 图像结果是否通过产品身份、平台比例与移动端文字安全区检查？
