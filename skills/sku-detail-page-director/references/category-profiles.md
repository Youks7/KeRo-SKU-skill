# 类目判断速查

阶段一仅在产品类目可合理判断时读取相应小节。它只帮助决定页面信息优先级和风险，不能代替商品资料。

| 类目 | 可优先呈现的已确认信息 | 默认高风险 |
| --- | --- | --- |
| 家居/收纳 | 真实使用场景、安装方式、空间关系、结构细节 | 承重、尺寸、容量、空间比例、过度豪宅化场景 |
| 美妆/个护 | 包装、可见质地、使用步骤、日常场景 | 功效、成分、备案、医疗化表达、伪前后对比 |
| 食品/饮品 | 包装、食用场景、已给出的口味/配料/规格 | 营养功效、产地、保质期、健康承诺 |
| 电子/配件 | 接口、外观、便携性、已确认的使用场景 | 兼容型号、功率、性能、安全认证 |
| 母婴/宠物 | 实际尺寸关系、清洁方式、真实场景 | 安全认证、年龄/体型适用、功能承诺、比例失真 |
| 服饰/配饰 | 可见版型、颜色、细节、穿搭场景 | 面料成分、尺码、过度修图、虚假上身效果 |
| 礼品/文创 | 包装、开箱、赠送场景、已确认内含物 | 礼盒内容、品牌故事、过度奢华化、误导规格 |

若产品不在表内，仍按事实账本工作：先描述看得见的形态，再询问最影响方向的资料；不要用类目刻板印象填补事实空白。
